## Evaluation Rubric (12 dimensions, 1–5 scale)

| Dimension | 1 (Poor) | 3 (Adequate) | 5 (Excellent) |
|-----------|----------|--------------|---------------|
| **Medical Filtering** | All transits included regardless of medical relevance | Some filtering but non-medical transits leak through | Only medically relevant transits included; non-medical events cleanly omitted |
| **Severity Rating Accuracy** | No ratings or inconsistent ratings | Ratings present but not consistently tied to the vulnerability map | Every rating justified by specific vulnerability table entries, health significator contacts, and sect analysis |
| **Vulnerability Map Overlay** | Transit interpreted generically without reference to the Medical Profile | Some references to the vulnerability map | Every transit interpretation cites specific vulnerability scores, affliction scan entries, or vitality assessment data |
| **Convergence Identification** | No convergence windows identified | Some clustering noted | Convergence windows named with date ranges, all contributing transits listed, body system convergence explained |
| **Healing Window Identification** | Supportive transits ignored | Some trines noted | Healing windows explicitly dated with practical scheduling guidance |
| **Health Context Integration** | Health Context ignored when provided | Context mentioned once | Context anchors the interpretation; every section speaks to stated concerns; triple confirmations noted |
| **Date Specificity** | No dates; vague periods | Some dates | Every finding has a specific date or date range; slow-transit durations noted |
| **Midpoint Integration** | Midpoints ignored | Some midpoints mentioned | Health-significant midpoints in table format with medical interpretation and severity ratings |
| **Ethical Framing** | Diagnostic or predictive language | Mostly appropriate | Flawless: "traditional association," "area to monitor," "constitutional pattern"; no causation; disclaimer prominent |
| **Accessible Language** | Heavy jargon | Mixed | Consistently clear; all terms defined; a person with no astrology knowledge can understand the health timing |
| **Proportional Depth** | All transits get equal treatment | Some differentiation | ELEVATED transits get substantial treatment; NOTABLE brief; SUPPORTIVE concise; length proportional to severity |
| **Synthesis Quality** | No convergence/healing synthesis | Some grouping | Convergence and healing windows clearly identified; Key Takeaways distill the period; wellness perspective is date-specific |

### Scoring Guide
- **48–60:** Publication quality. Ready for client delivery.
- **36–47:** Good draft. Minor revisions needed.
- **24–35:** Adequate but needs more depth or specificity.
- **Below 24:** Needs fundamental rework.
