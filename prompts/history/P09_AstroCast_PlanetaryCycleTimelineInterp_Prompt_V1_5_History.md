## Current changes

Aligned with the AstroCast 1.3.4 exports; the Input line names 1.3.4 (R3). F (T2-2, T5-3): Mercury's cycle runs about a year, as Venus's does, and a cycle's duration is compared with the mean interval between returns; the Return and Next Return rows count their passes, and a Passes of 0 is an estimated date. R2: a header carrying `**Calendar:** dates before 1582-10-15 are on the Julian calendar` means every date is on the calendar in force; nothing to convert. R1 not applied: the cycle export prints no orb. H (R8): the dated windows name the major period when a node's firdaria period is undivided. Older lines made true: the header names the natal planet's longitude and sign only; the Retrograde Passes table labels its passes 1st, 2 and Final, with no direction; a snapshot holds longitudes and signs only; the export carries no time-lord section.

Shared operating rules 1.0 are embedded where applicable. History and operator evaluation material have been extracted. ## 9. Evaluation Rubric (10 dimensions, 1–5 scale)

| Dimension | 1 (Poor) | 3 (Adequate) | 5 (Excellent) |
|-----------|----------|--------------|---------------|
| **Planet Identification** | Wrong planet or generic | Correct but inconsistent | Planet-specific narrative shapes every section |
| **Narrative Arc** | Phases listed without story | Some threading | Five phases form coherent story |
| **Phase Spacing Analysis** | Ignored | Noted but not interpreted | Uneven spacing explicitly analysed |
| **Retrograde Integration** | Triple crossings ignored | Mentioned but not interpreted | Triple crossings explained; single-pass cycles acknowledged |
| **Current Position Integration (v1.1)** | Not noted / passing mention | Mentioned once | Woven throughout; narrative tense appropriate; practical guidance tied to position |
| **Snapshot Integration** | Ignored when present | Some snapshot data | Angular planets and Moon at each phase integrated |
| **Honest Complexity (with Timeline Narrative Discipline)** | Phase dates predicted as events / only positive or only negative | Both acknowledged; occasional predictive drift | Phase dates as register-markers; difficulty framed as register; Discipline observed throughout |
| **Accessible Language** | Heavy jargon | Mixed | Consistently clear |
| **Timing Integration** | Timing data ignored | Some timing noted | Profection, firdaria, ZR woven through |
| **Convergence Quality** | No synthesis | Some grouping | Convergences identified; companion PR noted when paired |

### Scoring Guide
- **40–50:** Publication quality.
- **30–39:** Good draft.
- **20–29:** Adequate but thin.
- **Below 20:** Needs rework.
