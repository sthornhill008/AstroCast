# AstroCast Voice Defaults User Guide

**Version:** 1.1  
**Date:** 2026-09-08  
**Supersedes:** `AstroCast_VoiceDefaults_UserGuide.md` for current use; the earlier file remains unchanged.

## Setting precedence

Each current prompt is self-contained. Resolve its subject/mode first, then explicit local settings, the research preset, compatible inherited settings, and its family default. Explicit voice always wins. A later explicit correction changes only the named field.

`Context: unvarnished and honest` selects candid third-person research for any personal subject, public or private. It is recognized only as an affirmative operator instruction or designated context. Quoted examples, negated phrases, and occurrences in Note/Notes/Source do not activate it. It does not authorize external biography, activate medical analysis, or change output format.

`Unvarnished mode`, `disregard sensitivity settings`, `don't sugar-coat it`, and `give it to me straight` change candor only. Voice retains its otherwise resolved value.

## Family defaults

| Family | Default / research behavior |
|---|---|
| Personal natal, transit, return, relocation, daily | Client second-person; public non-client third-person; research third-person about the named native. |
| Synastry | Address both people according to the submission; research names both in third-person with balanced, directional attribution. |
| Composite | The relationship is the grammatical subject in every mode. Research is candid third-person about the relationship. |
| Horary and electional | Address the querent/decision by default; research describes the querent, question, act, and candidates in third-person. |
| Personal event | The event remains the main subject; personal components follow client/research/explicit voice. |
| Mundane/institutional | The collective, institution, nation, or cycle remains the subject. Research increases candor without inventing a native. |
| Mundane with natal overlay | Resolve collective and personal sections separately. Research changes the personal overlay, not the mundane sections. |
| Medical/decumbiture | Apply the family public-figure restriction and educational boundary before voice. Research never bypasses them. |
| Data/graphic | No interpretive voice preset. Use factual labels and preserve chart ownership. |

## Examples

- `Context: unvarnished and honest` → candid register plus third-person research.
- `Context: unvarnished and honest. Use second-person to Maria.` → candid second-person; the explicit voice wins.
- `Use third-person about Alex.` → third-person with the normal constructive register.
- `Unvarnished mode.` → candid register with the normal voice default.
- `Do not use "unvarnished and honest" mode.` → preset inactive.
