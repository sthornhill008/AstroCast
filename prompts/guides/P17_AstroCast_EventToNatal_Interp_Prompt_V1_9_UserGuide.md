## Producing the export (AstroCast 1.6.0)

A Type B synastry export made with **Points** ticked on the Chart panel's Houses section ("Include asteroids and Lilith") carries each chart's `## Asteroids and Lilith` section and `## Inter-Chart Aspects: Asteroids and Lilith`. This prompt sets them aside: it reads the event's own techniques, which do not use these points. With the box unticked, the default, the export is as before.

## Submission

Specify the subject, report period where relevant, context, focus, and any output override. For personal research use `Context: unvarnished and honest`. This does not permit external biography or activate medical analysis. An explicit voice instruction overrides the preset. For a blind test, remove names and biography while retaining chart settings and birth-time reliability.

## Family scope

Keep the event chart and natal chart owners distinct. Research uses third-person for the personal component while the event retains its route. Dual-context discipline is active whenever both event and natal contexts are supplied, regardless of public status; otherwise state missing context. Public status alone does not prohibit chart-grounded nonmedical symbolic discussion.
