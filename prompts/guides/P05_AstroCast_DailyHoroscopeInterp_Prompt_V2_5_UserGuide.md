# P05 AstroCast_DailyHoroscopeInterp_Prompt_V2_5 — User Guide

Version: 1.2. Date: 2026-11-28.

Use the [complete current prompt](<../Daily/P05_AstroCast_DailyHoroscopeInterp_Prompt_V2_5.md>), followed by the Daily Horoscope export and your request. All operational rules are embedded in that file. Version 2.5 has a rule for a birth time that is not confirmed: when the export's Birth Time Source reads Unknown or Not specified, the reading does not state houses, angles or a day or night chart as known, and with Unknown, where the export prints no house, each day is written by planet and theme. Entry and exit dates are given only where the export prints them. Historical excerpts are retained separately; they are not submission instructions.

## Submission

Specify the subject, report period where relevant, context, focus, and any output override. For personal research use `Context: unvarnished and honest`. This does not permit external biography or activate medical analysis. An explicit voice instruction overrides the preset. For a blind test, remove names and biography while retaining chart settings and birth-time reliability.

## Family scope

Subject: the native, consistently across every day. Preserve concise daily sections, quiet days, and no-glossary default. Health/wellbeing content is general reflection; technical medical analysis remains request-driven.

## Review

Check technical consistency, subject/voice, synthesis, relevant context, uncertainty, and output separately. Mark unavailable methods N/A. Record prompt version, model when available, input identity, date, resolved settings, and prose word count. Subjective resonance is not factual or scientific validation. Compare defaults, research, explicit voice override, missing data, and format override using the same inputs. Inspect every PDF page for clipping, wrapping, glyphs, stranded headings, and attribution.
