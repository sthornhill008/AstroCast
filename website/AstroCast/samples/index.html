How to read these. AstroCast writes the report: the positions, aspects and timings, as a plain file. An AI assistant, given that report and a prompt from the AstroCast prompt library, writes the reading: it presents the report, organises it and highlights the patterns in it. Each page says what it shows and how it was made.

The prompts are an aid to an astrologer, not a replacement for one. A reading is an interpretation, not fact.
