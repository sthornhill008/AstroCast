The full guides

These pages cover the first steps. Everything else is in the two guides, which you can read here or download:

  • AstroCast User Guide (PDF): from installing AstroCast to a finished report, panel by panel. Every button, box and setting is named as the program prints it.
  • Prompt Library Guide (PDF): how to make an export, choose the prompt, submit the two together and read what comes back.

In short

  1. Install AstroCast on Windows or on a Mac.
  2. On the Chart panel, enter a name, search for the birthplace, enter the date and time, and press Calculate & Save.
  3. Press Save Markdown to write the chart report.
  4. To read the report with an AI, pick the prompt for the report you made, and paste the prompt and the report into a chat. Your first chart and reading has every step.
