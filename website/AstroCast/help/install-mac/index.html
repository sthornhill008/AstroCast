For a Mac with Apple silicon, running macOS 15 or later

Install AstroCast

  1. Download the Mac disk image (the file ending in .dmg) from the download section of the AstroCast page, and open it.
  2. Drag AstroCast into Applications.
  3. Open it from Applications or Launchpad. The app is signed and notarized, so macOS opens it without a warning.

Where things live on a Mac

WhatWhere
The program/Applications/AstroCast.app
Your saved charts~/Library/Application Support/AstroCast/astrocast.db
Logs~/Library/Application Support/AstroCast/logs
The map key (optional)~/Library/Application Support/AstroCast/carto-key.txt

The Application Support folder and the database are created the first time the app runs.

Finding the Library folder. ~ is your home folder. In the Finder, hold Option and open the Go menu to see Library.

The map key is only for the Map panel's background. The map's background explains it.

Upgrading, and moving charts from Windows

Install the new version over the old one. Your charts, settings and logs are kept.

The Windows and Mac versions keep separate databases. To carry your charts from one to the other, use Export Backup on the Export panel of the first computer, which writes every saved chart to one file, and Import Backup on the second.
