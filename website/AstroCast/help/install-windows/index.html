Install AstroCast

  1. Download the Windows installer (the file ending in .msi) from the download section of the AstroCast page, and run it.
  2. Windows SmartScreen will say the publisher is unknown, because the installer is not signed with a Windows certificate. Choose More info, then Run anyway.
  3. Accept the licence shown on the installer's first page and finish.

AstroCast installs for the current user only, and needs nothing else: the .NET runtime and the Swiss Ephemeris are inside.

The warning appears once. SmartScreen asks once before the installer runs.

Where things live on Windows

WhatWhere
The program%LOCALAPPDATA%\Thornhill Computer Software\AstroCast\AstroCast.exe
Your saved chartsastrocast.db in that same folder
Logsthe logs folder in that same folder
The map key (optional)carto-key.txt in that same folder

The map key is only for the Map panel's background. The map's background explains it.

Upgrading

Install the new version over the old one. Your charts, settings and logs are kept; the installer never replaces the database.
