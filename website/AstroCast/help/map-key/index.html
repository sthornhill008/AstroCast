Why the map is blank at first, and how to add a free key

Why the map is blank

The Map panel draws astrocartography: lines on a world map where each planet was rising, setting, or at its highest or lowest point at the moment of birth.

Under the lines, the map window can show a street map from CARTO, a map service that needs a key. AstroCast ships without one. The map still works and draws every line and marker, on a blank background, and its legend says Base map unavailable: no CARTO key.

You do not need a key to use the map. Add one only if you want the background.

Add the map background

  1. Request a free key at CARTO's basemaps page. CARTO's terms allow free non-commercial use within a monthly allowance, and require the credit the map already shows.
  2. Save the key, by itself, in a plain text file named carto-key.txt.
  3. Put the file in the right folder for your computer (the table below).
  4. Start AstroCast again. The map window now draws the background.
ComputerWhere carto-key.txt goes
WindowsBeside AstroCast.exe, in %LOCALAPPDATA%\Thornhill Computer Software\AstroCast
Mac~/Library/Application Support/AstroCast

On a Mac. ~ is your home folder. In the Finder, hold Option and open the Go menu to see Library.

Your key stays with you

The key is yours and stays on your machine; AstroCast never writes it anywhere else. With a key in place, the only internet traffic from the map is the requests for map tiles, sent as you pan and zoom.

The map background is served by CARTO from OpenStreetMap data, and the map credits both.
